1. PROJECT GOAL
------------------------------------------------------------------------
The goal of this phase is to:
1. Connect the React/Vite frontend UI to the Python FastAPI backend.
2. Route manual credit underwriting predictions and CSV batch processing
   through the actual scikit-learn Random Forest model (models/credit_risk_model.pkl).
3. Compute exact local decision explainability (SHAP-like values) in the
   Python backend and render a premium waterfall chart and narrative explanations
   on the frontend dashboard.

------------------------------------------------------------------------
2. ARCHITECTURE OVERVIEW
------------------------------------------------------------------------
The system operates as a full-stack predictive interface:

React (Vite, 127.0.0.1:3000)
       ↓ (POST /predict with JSON payload)
FastAPI (Uvicorn, 127.0.0.1:8000)
       ↓ (Loads models/credit_risk_model.pkl)
Random Forest Classifier (200 Estimators)
       ↓ (Traverses decision paths to compute local attributions)
JSON Response (Default Prob, Risk Level, Base Value, SHAP Values)
       ↓ (Formatted in API client and scaled to percentages)
Interactive SHAP Dashboard (Waterfall Chart & Narratives)

3. MATHEMATICAL MODEL FOR LOCAL EXPLAINABILITY (TREE SHAP)
------------------------------------------------------------------------
To explain why a specific applicant got a high or low default probability
without installing heavy, slow external libraries like `shap`, we implemented
a fast and mathematically exact tree interpreter algorithm in the backend:

1. **Baseline Expectation (Base Value)**:
   At startup, we compute the average expected default probability at the
   root node of all 200 estimators. This is constant for a given model and
   represents the baseline risk of the population.
   
2. **Decision Path Traversal**:
   When an applicant is sent to `/predict`, we run the instance down each of the
   200 decision trees. For each tree, we retrieve the sequence of node IDs.
   
3. **Change in Expectation**:
   At each parent node split, we check the feature used to split. The difference
   in expected probability between the child node and parent node is computed:
     Δ = expectation(child_node) - expectation(parent_node)
   This difference is credited to the splitting feature.

4. **Ensemble Averaging**:
   We divide the local contribution of each feature by the number of estimators (200)
   and sum them across all trees:
     contribution(feature) = Σ [ Δ_tree / 200 ]
     
5. **Exact Match Guarantee**:
   Because the prediction probability is the average of the leaf predictions of all
   estimators, and the path from root to leaf represents a telescoping sum of
   visual expectations, the baseline value plus the sum of all feature contributions
   adds up EXACTLY to the prediction probability:
     Prediction = Base_Value + Σ [ contributions(features) ]

5. HOW TO RUN THE PROJECT
------------------------------------------------------------------------

### Step A: Start the FastAPI Backend
Ensure Python dependencies are installed and run the FastAPI server:
```bash
pip install -r requirements.txt
uvicorn backend.main:app --reload
```
This runs the backend on `http://127.0.0.1:8000`.

### Step B: Start the React Frontend
Navigate to the frontend folder, install packages and start the dev server:
```bash
cd frontend
npm install
npm run dev
```
This runs the UI on `http://localhost:3000`.
The application automatically points to the backend on `127.0.0.1:8000`.
